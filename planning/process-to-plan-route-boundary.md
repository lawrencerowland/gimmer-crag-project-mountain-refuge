# Process-To-Plan Route Boundary

Status: public boundary note for the watchable Gimmer Crag mountain-refuge lab
Created: 2026-07-04

This published mirror makes one route inspectable:

`process/Petri fragment -> valid execution -> schedule/SMC/WBS projection -> caveat`

It is not the whole process-to-plan programme.

## What This Published Lab Can Claim

- A selected schedule candidate can witness one valid execution of the embedded process/Petri
  fragment.
- The SMC expression and WBS view are projections of that witness.
- The projection preserves task identity, ordering, parallel blocks, resource settings, and makespan.
- The projection deliberately forgets unchosen alternatives, guard rationale, resource provenance,
  and risks not modelled in the toy net.
- A plan view is too thin to reconstruct the original process without extra assumptions.

## What It Should Not Claim

- It is not a formal proof that every project plan is functorial.
- It is not a general route-planning engine.
- It is not the first public receiver for dynamic project states.
- It does not expose record-level DEVONthink provenance.

## Broader Scenario Boundary

The broader `processes to plans` foray has a private hill/travel scenario under review. That scenario
is useful because real route planning contains intention, constraints, resources, preferences,
weather, body state, and contingency decisions that should not be forced into a Petri net too early.

This public mirror only names the concept-level boundary. Detailed source notes, record titles, links,
and provenance stay in the private Portfolio Wave working folder until deliberately reviewed for
public use.
